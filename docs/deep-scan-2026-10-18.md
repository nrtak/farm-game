# Bug and consistency scan — October 18, 2026

## Confirmed issues and fixes

1. **Legacy-save reload could retain unsaved crops (medium).** The loader applied only the crop entries present in the loaded save. Existing later beds retained their current crop state, potentially introducing harvests absent from that save. Reproduced with a valid one-entry legacy crop array and a ripe unsaved crop in bed 50. Reset crop state before applying saved entries, retaining the stable positions and restoring valid saved crops. The regression failed before the fix and passed afterward.
2. **Seasonal music restarted at ordinary map boundaries (low).** Farm, town and nature now share a seasonal score, but the theme switcher compared logical region keys rather than the selected recording. It now preserves playback and fade when the actual score is unchanged, while retaining season/weather/night/interior changes. Season changes indoors also no longer restart the same indoor score. Added coverage for region continuity and season-independent indoor playback.
3. **Storage UI understated upgraded capacity (low).** The chest text always said 999 per item although house upgrades increase capacity to 1,998 or 2,997. The message now uses the same capacity function as inventory transfers. Added a check at the highest upgrade.

## Scope

Reviewed recent terrain/sign presentation, projected cameras and sprites, dialogue resizing, save restoration and migration, farm bed indexing, audio selection/routing/pause, and static resource dependencies. No game asset dependency on an untracked file was found. Existing unrelated untracked files were left untouched.

The full regression runner covers map navigation, doors and collisions, farming/fishing/tea/mining, inventory and purchases, quests and relationships, routines/festivals, house and farm upgrades, weather and calendar, recovery and save round trips, and a full year of daily settlements. Two new regressions were added to the runner: deep_scan_regressions and dialogue_resize. The latter checks portrait and narrative panels at 1311×603, 844×390, 667×375, 568×320 and 390×844.

## Validation

All 68 existing regression checks passed. Both new regression scripts passed separately (70 distinct checks total), and targeted save/audio reruns passed after the fixes. The audio suite additionally passed with the desktop graphics/audio runtime rather than headless mode. `git diff --check` passed. Packaged verification is recorded in the local review manifest. Logs are under local-draft: deep-scan-checks.log, deep-scan-fix-checks.log, deep-scan-resize.log, and deep-scan-live-audio.log. Tests use isolated save sessions; the normal player save is not used.

## Limits

Desktop automated validation and source review do not prove the absence of every bug. Physical iPhone/iOS audio, touch, thermal performance, and a sustained manual gameplay session were not tested. No upload or external release was performed.
